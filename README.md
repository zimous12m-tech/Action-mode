# O Meu Plano de Ação — Versão 4

Aplicação web estática (HTML, CSS e JavaScript puro) desenhada para gerir ciclos com etapas ordenadas, tarefas por etapa, pesos, cálculo automático de horas por etapa, suporte a várias moedas ou avaliação não-financeira e registo de expectativas e conclusões tanto **por etapa** como **no fim do ciclo**.[cite: 8]
